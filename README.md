# MObPr_LB1
4.Секретный сейф – открывать приложение только при правильной последовательности наклонов

Инструкция по использованию:

Скачать apk и установить приложение 
При первом запуске установите пароль: нажимайте кнопки ↑ ↓ ← → (минимум 3 направления)
Нажмите "Установить пароль"
Для открытия: повторите сохраненную последовательность реальными наклонами телефона
При успешном вводе сейф откроется и покажет секретное сообщение
